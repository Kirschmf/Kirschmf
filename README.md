## Projetos em destaque

### MKF Solutions · Interface interativa e responsiva

Site e portfólio em React, TypeScript e Vite. Na seção **Experimente**, uma simulação de pedidos permite testar aprovação, estoque insuficiente e recuperação de falhas de registro.
