## About

I am a full-stack developer from Porto Alegre, Brazil, focused on turning business problems into clean, fast and maintainable web products.

My strongest work sits at the intersection of frontend engineering, commerce workflows and product experience: interfaces that feel polished, systems that are easy to evolve, and codebases that can survive real clients, real deadlines and real growth.

## What I Build

- Modern web applications with React, Next.js, TypeScript and Tailwind CSS.
- B2B e-commerce experiences, storefronts, catalogs and institutional websites.
- Authenticated products with API consumption, database integration and structured UI systems.
- High-impact landing pages with strong visual direction, performance and responsive behavior.
- Client-ready projects with practical architecture, reusable components and quality checks.

## Engineering Principles

- Build interfaces that are useful first, beautiful second, and never confusing.
- Keep architecture simple until complexity earns its place.
- Prefer typed contracts, reusable components and predictable state over clever shortcuts.
- Treat performance, accessibility and responsive behavior as product quality, not polish.
- Document the parts of a project that future developers will actually need.
